广告

怎么加一篇公众号文章

01

存来源

在 data/sources.yaml 加一条：标题、公众号、原文链接、日期（没有就写「待补」）。

02

找仓库写内容

文章提到的插件，顺着名字去 GitHub 找官方仓库、读 README，在 data/plugins.yaml 里补 repo / install / summary / features，并把来源塞进 refs 作为参考。

03

重新生成

跑 python3 tools/build_data.py && hugo --minify，仓库确认数、搜索索引全部自动重算。

正文一律以官方仓库 README 为准，公众号文章只作发现来源与补充说明。完整收录方法
