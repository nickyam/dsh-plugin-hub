这些卡片是怎么来的

01

找到官方仓库

按插件名字去 GitHub 搜，确认仓库确实是它、维护者确实是这批人。查不到可信仓库的名字，一律不建条目。

02

读 README 写卡片

在 data/plugins.yaml 里补 repo / install / summary / features，全部按 README 写，不抄第三方介绍。

03

重新生成

跑 python3 tools/build_data.py && hugo --minify，统计、搜索索引、分页清单全部自动重算。

只收需要自己动手安装的插件，官方开箱即用的内置能力不建条目。完整收录方法
